## ✏️ Content Kaise Change Karein

Aap `index.html` file ko open karke aasani se text badal sakte hain:

1. **Aapka Naam & Title**:
   - `index.html` me `<h1 class="hero-title">` me jaakar `Aapka Naam` ko apne asli naam se replace karein.
   - `<h2 class="hero-subtitle">` me apna profession (jaise "Full Stack Developer", "Graphic Designer", etc.) likhein.

2. **Social Links**:
   - Hero section me `class="social-links"` ke andar apne GitHub, LinkedIn aur Instagram profile links paste karein.

3. **About Me**:
   - `id="about"` section me apni actual bio, location, email aur experience stats daalein.

4. **Skills**:
   - `id="skills"` section me apne pasandeeda tools aur technologies add/remove karein.

5. **Projects**:
   - `id="projects"` section me apne real projects ke naam, description aur links update karein.

6. **Contact Info**:
   - `id="contact"` section me apna real phone number aur email address set karein.
